# Supply Chain Delivery Risk Dashboard

Power BI dashboard on 180k DataCo supply chain orders that tracks on-time delivery and finds where delays happen, with a scikit-learn model that predicts late deliveries at order time.

Work in progress

## Data
[DataCo Smart Supply Chain dataset](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis) (Kaggle, CC0: Public Domain). Download it and place the CSV in `data/raw/`.
